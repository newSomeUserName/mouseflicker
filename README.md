# MouseFinger

Управление курсором рукой через веб-камеру. В простое ≈ 0.2 МБ; камера и нейросеть работают
в отдельном процессе только пока режим включён (≈ 35–50 МБ).

Запуск: `mousefinger.exe` → иконка в трее. Рядом должны лежать `onnxruntime.dll` и папка `models\`.

## Управление
- **Курсор — «тачпад в воздухе».** Водите ладонью: медленно — курсор идёт точно и медленно,
  быстро — улетает далеко (как ускорение обычной мыши). Движение считается в размерах ладони,
  поэтому не зависит от того, как далеко вы от камеры. Убрали руку из кадра — курсор остался на месте.
- **Кулак = кнопка.** Сжал и раскрыл — клик. Сжал и повёл — перетаскивание (начинается, когда сжатую
  руку сдвинули примерно на треть ладони).
- Клик попадает туда, где курсор был до начала сжатия, — сам жест курсор не сдвигает.
- Кольцо у курсора заполняется по мере сжатия и краснеет при нажатии.

| Клавиши        | Действие                                              |
|----------------|-------------------------------------------------------|
| Ctrl+Alt+M     | включить / выключить (или клик по иконке в трее)      |
| Ctrl+Alt+C     | что делает кулак: левый (клик/перетаскивание) → правый → двойной |
| Ctrl+Alt+S     | прокрутка: сжать кулак и тянуть вверх/вниз            |
| Ctrl+Alt+P     | показать / скрыть превью                              |
| Ctrl+Alt+R     | заново найти руку                                     |

## Обучение на вашей руке (рекомендуется)
Правый клик по иконке → **«Обучить на моей руке…»**. 3 шага по ~10 секунд с подсказками на экране:
раскрытая ладонь → кулак → рука «как при работе» (расслабленная, полусогнутая). Водите рукой и
поворачивайте её. Затем программа обучает классификатор (доли секунды), показывает точность на
отложенных кадрах, сохраняет `hand_profile.bin` и сама включает управление. В превью — «кулак NN% (профиль)».
Повторить можно в любой момент (например, при другом освещении). Без профиля работают пороги из ini.

## Настройки (`mousefinger.ini`, правый клик по иконке → «Настройки…»)
- `Sensitivity` — скорость курсора. `Mapping=1` — абсолютный режим (курсор там, где рука).
- `FistClose` / `FistOpen` — пороги кулака. В превью видно текущее «кулак NN».
  Ложные клики — уменьшите `FistClose`, не срабатывает — увеличьте.
- `Gesture=1` — щипок вместо кулака.

## Живой тест на камере
`mousefinger.exe --track --test` — минута по сценарию с командами на экране (ладонь, клики по сигналу
«СЕЙЧАС!», рука как при работе, неподвижно, перетаскивание). Мышь не трогает, пишет `test.csv`.
`tools\test_eval.exe test.csv` — пропуски/лишние/ложные клики, задержка, дрожь, сравнение старой и новой
логики на той же записи и подбор порогов. Журнал запуска — `mousefinger.log`.

## Диагностика и проверка логики
- `mousefinger.exe --track --diag` — 30 секунд без управления мышью; пишет `diag.csv` и снимки `diag_*.bmp`.
- `tools\replay.exe diag.csv` — прогоняет записанную руку через логику управления (`control.h`) и печатает
  дрожь курсора и поведение кликов; `tools\replay.exe diag.csv sweep` — перебор параметров сглаживания.
- `tools\calib_eval.exe calib.csv` — повторяет обучение по записи калибровки и сравнивает со старым порогом.
- `tools\gesture_test.exe` — тесты признаков, обучения и связки с логикой нажатия (синтетическая рука).

## Состав
- `models/palm_detection.onnx`, `models/hand_landmark.onnx` — MediaPipe Hands из OpenCV Zoo (Apache 2.0).
- `onnxruntime.dll` — ONNX Runtime 1.20.1 (MIT). Если его нет, используется встроенный в Windows 11.

Сборка: `build.bat` (MinGW g++). Тест: `g++ -std=c++17 -O2 -static tools\replay.cpp -o tools\replay.exe`.
